# Contributing

Contributions that improve routing, decision quality, project templates, agent interoperability, or documentation are welcome.

Before submitting a change:

1. Keep reusable guidance independent of any single product.
2. Put product-specific examples under `examples/`.
3. For decision documents, describe the available approaches, decision triggers, tradeoffs, consequences, and what a project should record.
4. Keep agent entry files concise; deeper instructions belong under `.docs/agent-system/`.
5. Check changed Markdown links and verify that routing still points to the intended guidance.

Open a focused pull request that explains the problem the change solves and which docs or workflows it affects.
