# Search Technology Selection

## Database filtering
Use for exact fields, ranges, structured filters and small-to-moderate datasets. Index the actual query patterns.

## Database full-text search
Use when text search requirements are moderate and the primary database provides sufficient ranking, language support and indexing.

## Dedicated search engine
Use when typo tolerance, sophisticated ranking, faceting, autocomplete, multilingual analysis or independent search scaling materially improves the product.

## Semantic/vector retrieval
Use when meaning-based retrieval is valuable and exact lexical matches are insufficient. Define embedding lifecycle, authorization filtering, freshness and evaluation criteria.

Record searchable entities, required relevance behavior, filters, permission model, freshness target and operational owner.
