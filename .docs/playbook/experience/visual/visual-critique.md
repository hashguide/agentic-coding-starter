# Visual Critique

Review rendered interfaces with realistic data at desktop and mobile widths.

Evaluate:
- hierarchy: primary information and action are visually clear;
- alignment: elements share deliberate edges and grids;
- spacing: repeated relationships use repeated spacing;
- typography: levels are distinct without excessive sizes or weights;
- color: semantic and accent colors have defined jobs;
- surfaces: cards, borders and elevation communicate structure rather than decoration;
- density: information volume fits the task and audience;
- states: hover, focus, selection, disabled, loading and error states are coherent;
- consistency: the same interaction looks and behaves the same across the product;
- responsiveness: hierarchy survives narrower widths without accidental overflow or buried actions.

Describe findings in terms of the design-system rule or user comprehension problem they violate, then verify the corrected screen visually.
