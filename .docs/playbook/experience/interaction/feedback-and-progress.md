# Feedback and Progress

Match feedback to duration, importance and persistence.

- Immediate visual state: direct response to hover, selection or local interaction.
- Inline pending state: short operation tied to a specific control or region.
- Skeleton: initial content whose layout is predictable and will arrive soon.
- Determinate progress: work where meaningful completion can be measured.
- Indeterminate running state: work duration is unknown but activity is confirmed.
- Toast: brief noncritical confirmation that does not require later retrieval.
- Persistent activity/status: asynchronous work or events users may revisit.
- Notification: completion or attention that may occur after the user leaves the active context.

The interface should distinguish accepted, queued, running, succeeded and failed work when those states materially differ.
