# Selection and Bulk Actions

Use persistent multi-selection when users repeatedly perform the same action across several items. Expose selection count, scope, select-all semantics, filtered-selection behavior, and a clear way to exit selection mode.

For destructive or irreversible bulk work, summarize the affected scope and use confirmation proportional to impact. For reversible changes, an undo flow may preserve speed better.

When selection spans pagination or server-side filters, define whether "select all" means the current page, currently loaded items, or the full filtered result set.
