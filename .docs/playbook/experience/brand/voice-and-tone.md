# Brand Voice and Tone

Voice is who you are. Tone is how you adapt to the situation. Voice is consistent across every word in the product; tone shifts based on context — an error message and an onboarding celebration are written in the same voice but at very different tones.

## The Voice Spectrum Exercise

Position the brand on each of these axes by choosing a point between the two extremes:

| Axis | One end | ←——→ | Other end |
|---|---|---|---|
| **Formality** | Formal / professional | | Casual / conversational |
| **Affect** | Serious / earnest | | Playful / lighthearted |
| **Expertise signal** | Expert / technical | | Approachable / plain |
| **Confidence** | Authoritative | | Collaborative |

**Example positioning for a productivity tool for developers:**
- Formality: casual-leaning (not stiff, but not slang)
- Affect: slightly serious (the work matters) with occasional wit
- Expertise: expert-leaning but never condescending
- Confidence: authoritative but inviting

Write a one-paragraph brand voice guide based on these positions:

> We're the capable colleague who's been in the industry long enough to know what matters. We're direct — we don't pad sentences with pleasantries. We trust the reader to be smart. We occasionally make a dry observation, but we're never joking when something breaks.

This paragraph becomes the reference for all content writers, engineers writing error messages, and AI tools generating copy.

## Tone Shifts by Context

The voice stays constant; the tone is the variable. The same brand that is warm and encouraging during onboarding is more measured and clear-headed in an error state.

| Context | Tone | Example |
|---|---|---|
| **Onboarding / first use** | Encouraging, optimistic, brief | "You're set up. Here's where most people start." |
| **Empty states** | Neutral, action-oriented | "No projects yet. Create your first one to get started." |
| **Success states** | Warm, specific | "Invoice sent to client@example.com." |
| **Error messages** | Clear, calm, actionable — not apologetic | "Couldn't save. Check your connection and try again." |
| **Destructive confirmations** | Serious, precise, no humor | "Deleting your account permanently removes all your data. This cannot be undone." |
| **Marketing copy** | Most expressive version of the voice | Full personality — but the same personality |

## Patterns to Avoid

**Hollow affirmations:** "Great! Amazing! You're all set!" — these words inflate tone without adding meaning and feel patronizing after the first use.

**Vague errors:** "Something went wrong." — never acceptable when you can be specific ("Couldn't connect to the server. Try again in a few seconds.").

**False urgency:** "Act now before time runs out!" — erodes trust and doesn't fit a voice built on directness.

**Over-apologizing:** "We're so sorry, but unfortunately due to an error, it seems that your file couldn't be saved at this time." → "Couldn't save your file. Try again."
