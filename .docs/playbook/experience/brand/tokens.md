# Design Tokens

Design tokens are the named, shared values that constitute the design system: colors, spacing, typography, border radius, elevation, and motion. Every UI value should come from a token — raw hex codes and arbitrary pixel values in component code are a sign that the token system is incomplete or being bypassed.

## Naming Convention

Tokens use a three-level naming scheme:
- **Primitive tokens:** raw values (`--color-blue-500: #3B82F6`)
- **Semantic tokens:** purpose-named tokens that reference primitives (`--color-primary: var(--color-blue-500)`)
- **Component tokens:** component-specific tokens that reference semantic tokens (`--button-bg: var(--color-primary)`)

Only semantic and component tokens are used in component code. Primitive tokens are only referenced by semantic tokens. This means changing the primary color requires updating one token.

## Color Tokens

```css
:root {
  /* Primitive scale (generated by Tailwind or manually) */
  --color-brand-50: #eff6ff;
  --color-brand-100: #dbeafe;
  --color-brand-500: #3b82f6;
  --color-brand-600: #2563eb;
  --color-brand-700: #1d4ed8;

  --color-neutral-0: #ffffff;
  --color-neutral-50: #f9fafb;
  --color-neutral-100: #f3f4f6;
  --color-neutral-200: #e5e7eb;
  --color-neutral-500: #6b7280;
  --color-neutral-700: #374151;
  --color-neutral-900: #111827;

  /* Semantic color tokens */
  --color-primary: var(--color-brand-500);
  --color-primary-hover: var(--color-brand-600);
  --color-primary-active: var(--color-brand-700);

  --color-bg-base: var(--color-neutral-0);
  --color-bg-subtle: var(--color-neutral-50);
  --color-bg-muted: var(--color-neutral-100);

  --color-text-primary: var(--color-neutral-900);
  --color-text-secondary: var(--color-neutral-500);
  --color-text-on-primary: var(--color-neutral-0);

  --color-border: var(--color-neutral-200);
  --color-border-focus: var(--color-brand-500);

  /* Semantic status colors */
  --color-success: #16a34a;
  --color-success-bg: #f0fdf4;
  --color-warning: #ca8a04;
  --color-warning-bg: #fefce8;
  --color-error: #dc2626;
  --color-error-bg: #fef2f2;
  --color-info: #2563eb;
  --color-info-bg: #eff6ff;
}
```

## Spacing Scale (8-Point Grid)

All spacing values are multiples of 4px, anchored to an 8px base:

```css
:root {
  --space-0: 0;
  --space-1: 4px;   /* 0.5× */
  --space-2: 8px;   /* 1× base unit */
  --space-3: 12px;
  --space-4: 16px;  /* 2× */
  --space-5: 20px;
  --space-6: 24px;  /* 3× */
  --space-8: 32px;  /* 4× */
  --space-10: 40px;
  --space-12: 48px;
  --space-16: 64px;
  --space-20: 80px;
  --space-24: 96px;
}
```

## Typography Scale

```css
:root {
  /* Font families */
  --font-sans: 'Inter', system-ui, -apple-system, sans-serif;
  --font-mono: 'JetBrains Mono', 'Fira Code', monospace;

  /* Type scale — size / line-height pairs */
  --text-xs:   0.75rem / 1rem;     /* 12px / 16px — captions */
  --text-sm:   0.875rem / 1.25rem; /* 14px / 20px — labels, secondary */
  --text-base: 1rem / 1.5rem;      /* 16px / 24px — body */
  --text-lg:   1.125rem / 1.75rem; /* 18px / 28px — lead */
  --text-xl:   1.25rem / 1.75rem;  /* 20px / 28px — section heading */
  --text-2xl:  1.5rem / 2rem;      /* 24px / 32px — page heading */
  --text-3xl:  1.875rem / 2.25rem; /* 30px / 36px — display */
  --text-4xl:  2.25rem / 2.5rem;   /* 36px / 40px — hero */

  /* Font weights */
  --font-normal: 400;
  --font-medium: 500;
  --font-semibold: 600;
  --font-bold: 700;
}
```

## Border Radius

```css
:root {
  --radius-sm: 4px;
  --radius-md: 6px;   /* Default for most components */
  --radius-lg: 8px;
  --radius-xl: 12px;
  --radius-full: 9999px; /* Pills, badges */
}
```

## Elevation / Shadow

```css
:root {
  --shadow-sm: 0 1px 2px 0 rgb(0 0 0 / 0.05);
  --shadow-md: 0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1);
  --shadow-lg: 0 10px 15px -3px rgb(0 0 0 / 0.1), 0 4px 6px -4px rgb(0 0 0 / 0.1);
  --shadow-xl: 0 20px 25px -5px rgb(0 0 0 / 0.1), 0 8px 10px -6px rgb(0 0 0 / 0.1);
}
```

## Motion Tokens

```css
:root {
  /* Duration scale */
  --duration-fast: 100ms;   /* Micro-interactions: hover, toggle */
  --duration-base: 200ms;   /* Standard transitions */
  --duration-slow: 300ms;   /* Larger state changes: modal open, drawer */
  --duration-deliberate: 500ms; /* Page transitions, emphasis animations */

  /* Easing curves */
  --ease-default: cubic-bezier(0.4, 0, 0.2, 1);     /* Standard — smooth in/out */
  --ease-in: cubic-bezier(0.4, 0, 1, 1);             /* Exiting elements */
  --ease-out: cubic-bezier(0, 0, 0.2, 1);            /* Entering elements */
  --ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);  /* Playful overshoot */
}
```
