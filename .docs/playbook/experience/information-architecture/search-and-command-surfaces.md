# Search and Command Surfaces

## Search
Use when users know or can describe the object/content they need. Define searchable fields, ranking, permissions, empty results, keyboard behavior and filtering.

## Command palette
Use for frequent users who benefit from fast navigation and actions across many areas. Commands should complement understandable navigation rather than compensate for poor IA.

## Filters
Use to narrow a visible collection by known attributes. Preserve filter state in the URL when users benefit from sharing, bookmarking or browser history.

## Recent and pinned items
Use when repeated return to a small working set is common.

Choose discovery mechanisms from dataset size, user expertise, task frequency, and whether the user knows the target or is exploring.
