# Page, Tab, Drawer, Modal, or Inline

## Dedicated page or route
Use for substantial, linkable, revisited work with its own navigation or history. Pages support deep interaction and refresh/recovery well.

## Tab
Use for alternate peer views within the same object and task context.

## Drawer / side panel
Use when users need meaningful detail or editing while retaining the list/workspace behind it. Provide a direct-link strategy when the content may be shared or revisited.

## Modal
Use for short, focused decisions or small forms where interruption is intentional. Keep long, branching, or frequently revisited workflows out of transient dialogs.

## Inline expansion/editing
Use for small contextual changes where navigation would add more friction than clarity.

## Split view
Use when users repeatedly compare or move between a collection and one selected item, such as mail, tickets, files, or logs.

Choose from depth of work, need for persistent URL/history, context retention, screen space, and mobile behavior. Record the selected surface in the feature experience spec.
