# Mobile Information Architecture

Responsive design may require a different navigation and task sequence, not only smaller dimensions.

For each desktop surface decide:
- which content is essential on small screens;
- which secondary panels become routes, sheets or accordions;
- how global navigation changes;
- whether dense tables scroll, simplify, or become item lists;
- where primary actions remain reachable;
- how back navigation restores context and scroll position.

Preserve the same conceptual model across devices even when the presentation changes.
