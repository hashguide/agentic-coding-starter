# Landing Page Layout

The landing page is the primary conversion surface. Every structural decision — hero layout, section order, CTA placement — affects whether a visitor becomes a user. The goal of the page is singular: get the visitor to take one specific action (start trial, sign up, book demo).

## Hero Layout Options

### Option 1: Centered Text + Visual Below

```
[Nav]
[centered headline]
[centered subheadline]
[CTA button]
[Product screenshot or illustration below]
```

**When it fits:** Products with a strong, punchy headline. Works when the visual context needs to load below the fold — the headline does the heavy lifting first.

### Option 2: Split-Screen — Text Left / Visual Right

```
[Nav]
[Left: headline + subheadline + CTA]  [Right: product screenshot or animation]
```

**When it fits:** When the product has a recognizable visual interface worth showing above the fold. The visual immediately demonstrates what the product is, reducing ambiguity.

### Option 3: Full-Bleed Visual with Overlaid Text

```
[Nav]
[Full-width product screenshot or hero image]
[Headline + subheadline + CTA overlaid on or below the visual]
```

**When it fits:** Products with a visually striking interface or for design-forward consumer products where brand is the primary message. Requires the visual to communicate even before the text is read.

## Page Section Order

A landing page that converts follows a persuasion sequence, not a feature catalog:

1. **Navigation** — Logo + primary nav links + primary CTA button (sign up / try free)
2. **Hero** — Headline, subheadline, primary CTA — what the product does and for whom
3. **Social proof / logos** — Customer logos or "trusted by X companies" — immediate trust signal
4. **Problem statement** — The pain or situation the visitor is in. Demonstrates empathy before pitching solution.
5. **Demo / solution** — How the product solves the problem. Screenshots, short video, interactive demo.
6. **Feature highlights** — Three to five specific capabilities. Each tied to a benefit, not a feature name.
7. **Testimonials** — Quotes from real customers. Include name, role, company.
8. **Pricing** — Or a "simple pricing" section with a link to the full pricing page.
9. **Final CTA** — Repeat the primary action. Visitors who scroll the whole page are interested.
10. **Footer** — Navigation, legal links, social links.

## One Primary CTA Per Visible Section

Each section of the page must have at most one primary call-to-action. Multiple competing CTAs in the same visual field dilute each other. If a section must present two options, make one primary (filled button) and one secondary (text link or ghost button).

**Primary CTA:** "Start free trial" or "Get started" — one consistent label throughout the page.

**Secondary CTA (if needed in the hero):** "See how it works" — links to the demo section below or a product tour.
