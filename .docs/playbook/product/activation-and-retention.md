# Activation and Retention

Define the observable moment when a new user receives meaningful value. Build onboarding around reaching that moment with the least required setup.

Choose onboarding patterns from dependency structure:
- inline guidance for context-specific learning;
- checklist for independent setup tasks;
- wizard for ordered dependent decisions;
- sample/demo state when users understand value better by seeing a completed example;
- import/connect flow when existing data is required to produce value.

Retention should correspond to the product's natural value cadence. Identify the repeated behavior that demonstrates continued value and the product conditions that make returning worthwhile.
