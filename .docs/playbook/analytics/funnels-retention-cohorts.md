# Funnels, Retention, and Cohorts

Use funnels for ordered journeys with a meaningful start and success point. Define whether steps must occur in order, within what time window, and how repeated attempts are treated.

Use retention when repeated value is expected. Choose the returning behavior that represents value rather than generic login activity.

Use cohorts to compare users who share a start period, acquisition source, plan, persona, feature exposure, or other relevant property.

Segment only when the population remains large enough and the distinction can change a product decision.
