# Reusable Product Engineering Playbook

This directory is reusable guidance. It provides options, selection criteria, tradeoffs, implementation concerns, and review criteria. It does not define what the current project must do.

## How to use a playbook document

1. Confirm the document applies to the current task.
2. Compare the approaches against current project requirements and constraints.
3. Select the approach that fits the product.
4. Record the selected behavior or architecture in `../project/`, `../features/`, or `../decisions/`.
5. Implement from project truth.

Most files carry frontmatter with `domain` and `topics`. Repository skills and `ROUTING.md` use these boundaries to keep context focused.
